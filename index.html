Do banco de dados à interface. Software pensado de ponta a ponta.

Sou Ryan Moreira, desenvolvedor full-stack e estudante de Engenharia de Software. Trabalho como Desenvolvedor de Sistemas na Itpower Software, construindo e mantendo sistemas web e APIs para clientes do setor de seguros.

No dia a dia uso ColdFusion, JavaScript e SQL Server. Fora do expediente, exploro React, Node.js, Java com Spring Boot e Python, e hoje estou focado em IA Generativa: LLMs, agentes e como levar isso para produção com a AWS.
